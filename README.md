# M. Rizki Ramadhani — Portfolio

Personal portfolio website for my projects, experience, and the things I’m learning in web development and IT.

🌐 **Live site:** https://rizkiramadhani561.github.io/  
💻 **GitHub:** https://github.com/RizkiRamadhani561  
🔗 **LinkedIn:** https://www.linkedin.com/in/m-rizki-ramadhani

## About this project

I built this site to bring my work into one place. It gives visitors a quick look at selected projects, the technologies I use, my experience, and ways to get in touch.

The design takes a bold, retro-inspired direction, with bright accent colors, compact typography, motion, and a few interactive details. I wanted it to feel like my own space rather than a generic portfolio template.

## What you can find here

- **Selected projects** with links to explore the work and source code.
- **Skills and experience** across web development, data handling, IT support, and operations.
- **Interactive details**, including animated sections, project filters, FAQ items, and a small Snake game.
- **Contact links** for email, LinkedIn, and GitHub.
- **Visitor counter** powered by GoatCounter.

## Built with

- **Next.js 15** and **React 19**
- **TypeScript**
- **Tailwind CSS 4** and custom CSS
- **Framer Motion** for interface animations
- **GSAP**, **Lenis**, and **Three.js** for motion and visual effects
- **React Icons** for interface icons
- **GoatCounter** for visit statistics
- **GitHub Pages** and **GitHub Actions** for hosting and deployment

## Run it locally

You’ll need Node.js and npm installed.

```bash
git clone https://github.com/RizkiRamadhani561/RizkiRamadhani561.github.io.git
cd RizkiRamadhani561.github.io
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

To create a production build, run:

```bash
npm run build
```
